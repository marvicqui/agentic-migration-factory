# Agentic Migration Factory

An evidence-backed application rationalization and Azure migration planning system for synthetic portfolios: data quality, dependency groups, 7R candidates, target patterns, migration waves, risks, TCO assumptions, and approval history.

## Status

**Specification phase.** The MVP is advisory only and does not execute migrations.

## Planned capabilities

- Synthetic CMDB/RVTools-inspired application and server inventory.
- Deterministic validation and dependency graph.
- Bounded agents for inventory quality, rationalization, target architecture, wave planning, and TCO explanation.
- Versioned 7R rubric and approved target-pattern catalog.
- Human approval for final dispositions and wave decisions.
- Constraint-validated waves and reproducible TCO formulas.
- Non-production Bicep skeletons for selected patterns.

Do not connect to production vCenter, CMDB, Azure Migrate, or customer environments. Generated IaC is validated, not deployed automatically.
